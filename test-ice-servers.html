Console Commands

Copy and paste these commands in your browser console:

1. Test ICE Servers

testIceServers([
  {
    urls: [
      "turns:turn-130.averox.com:3478?transport=udp",
      "turns:turn-130.averox.com:3478?transport=tcp"
    ],
    username: "1767360372:@super_admin:ms.beep.gov.pk",
    credential: "XKLvRYyxtl09qjvAepmP+FkRmR8="
  }
]);

2. Check Current Servers

checkIceServers();

3. Restore Original Servers

restoreIceServers();
